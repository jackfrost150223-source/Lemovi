# Lemovi

Lemovi es un navegador integrado inicial para Android TV / Google TV, pensado para abrir páginas web de películas y reproducir el contenido que sea compatible con Android WebView.

## Compilar
El repositorio incluye GitHub Actions. Cada push a `main` y cada ejecución manual del workflow compilan una APK de depuración y la publican como artefacto descargable.

## Instalar
Descargá el artefacto `Lemovi-AndroidTV-APK`, extraé `app-debug.apk` e instalalo en Android TV.

## Alcance de esta primera versión
- Navegación web integrada.
- Campo para pegar una URL y botón IR.
- Controles básicos de atrás/adelante.
- Modo pantalla completa.
- Soporte de navegación por control remoto Android TV.

Algunos sitios pueden no reproducir por DRM, restricciones del proveedor, códecs o reproductores incompatibles con WebView. Esta versión inicial no garantiza compatibilidad con todos los sitios.
